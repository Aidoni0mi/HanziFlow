# Security

Threat model: untrusted imported files, microphone permission, user data, dependency supply chain, future cloud integration. Current mitigations: scoped SAF picker, random UUID private paths, size limits, PDF header and renderer validation, file cleanup on failure, parameterized SQLite SQL, no app internet permission, backup disabled, no secrets or user books in Git. No DRM bypass. PDF renderer remains a native parser; keep Android updated. No cryptographic secure deletion or sandboxing beyond Android. No automated security scan executed; CI generates dependency report and runs lint, not a full CVE audit. Before release add dependency verification/SBOM, CVE scanning, malicious import tests and permission review. Future backend must enforce auth, HTTPS and never embed secret API keys in APK. Report vulnerabilities privately to repository owner; never attach real voice/book data.

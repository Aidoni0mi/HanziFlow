# Contributing

Branch from main, make narrow commits, run `scripts/core-check.sh` (Kotlin CLI) and Gradle unit/lint/build. Add tests for each feature; do not claim Android behavior until device tested. Record new source, version, rights and coverage. Never commit books, personal voice recordings, secrets, keys or local configuration. Treat source data as untrusted; original educational content must be editorially reviewed. Keep PROJECT_STATUS, CHANGELOG and coverage in sync. No public redistribution of original code until owner selects license.

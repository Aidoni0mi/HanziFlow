# Product research and 0.3.0-alpha
Public product pages reviewed: https://www.trainchinese.com/v2/viewExplainTrainingAlg.php ; https://toneperfect.app/features ; https://laoshi.io/app/ ; https://www.superchinese.com/ . No private content, proprietary code or recordings copied.
Implemented: four self-rated review modes with a shared schedule; daily three-step practice; four original dialogues and local paste/save; listening recognition drill; on-device Android speech-to-text comparison for any HSK word, character or typed sentence (API 31+, installed Mandarin service). Not acoustic syllable scoring, no cloud fallback. Existing F0 trainer retained. 300 original provisional HSK1 Russian glosses, exact source IDs verified.
QA: fix serialized database writes and review busy/error state; explicit combined HSK7–9. Counts were verified in prior data check; reported HSK2 and grammar display failures cannot be reproduced without device screenshots. Grammar lists now display both new and cumulative counts. Not all competitor functions implemented: detailed phonetic scoring, native recordings, handwriting grading and animation, OCR, full licensed course and textbook dialogues, AI tutor, full Russian dictionary and grammar lessons remain open. No private textbooks bundled.
